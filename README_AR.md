# GridGate v0.5.0

## الجديد
- 2 أو 3 أو 4 لاعبين.
- Classic: 9×9 / 12×12 / 14×14، 10 جدران لكل لاعب، الهدف الجهة المقابلة.
- Race: 9×9 / 12×12 / 14×14، يبدأ الجميع من الصف نفسه والهدف الصف الأخير، 10 جدران.
- Center: 9×9 / 11×11 / 13×13، البداية من منتصف جوانب الرقعة، الهدف خانة المركز، 8 جدران.
- اللعب ضد AI: Beginner / Skilled / Veteran / Expert. في 3 أو 4 لاعبين تكون P1 أنت والبقية AI.
- Dark / Light theme. النمط الفاتح: خلفية بيضاء، Grid رمادي متلاشٍ، أزرق شفاف ولمعان، ورقعة بيضاء بفواصل رمادية.
- Online rooms تدعم الآن 2–4 لاعبين وتحفظ إعدادات منشئ الغرفة.
- مؤقت 32 ثانية Online ما زال Server-authoritative.
- Debug الشبكة محفوظ.
- التحكم بالجدار على الهاتف بالضغط المطول ثم التحريك والإفلات محفوظ.

## تشغيل محلي
```bat
npm install
npm test
npm run dev
```
ثم افتح:
`http://localhost:8787`

## نشر Cloudflare
```bat
npm install
npm run deploy
```
ثم استخدم رابط workers.dev نفسه.

## ملاحظة AI
Beginner عشوائي إلى حد كبير، Skilled يقيّم أقصر المسارات، Veteran يستخدم بحث Alpha-Beta بعمق 2، Expert بعمق 3 مع مرشحات جدران قريبة لتقليل عدد الفروع.
