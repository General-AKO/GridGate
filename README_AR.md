# GridGate v0.5.0

## الجديد
- 2 أو 3 أو 4 لاعبين.
- Classic: 9×9 / 12×12 / 14×14، 10 جدران لكل لاعب، الهدف الجهة المقابلة.
- Race: 9×9 / 12×12 / 14×14، يبدأ الجميع من الصف نفسه والهدف الصف الأخير، 10 جدران.
- Center: 9×9 / 11×11 / 13×13، البداية من منتصف جوانب الرقعة، الهدف خانة المركز، 8 جدران.
- اللعب ضد AI: Beginner / Skilled / Veteran / Expert. في 3 أو 4 لاعبين تكون P1 أنت والبقية AI.
- Dark / Light theme. النمط الفاتح: خلفية بيضاء، Grid رمادي متلاشٍ، أزرق شفاف ولمعان، ورقعة بيضاء بفواصل رمادية.
- Online rooms تدعم الآن 2–4 لاعبين وتحفظ إعدادات منشئ الغرفة.
- مؤقت 32 ثانية Online ما زال Server-authoritative.
- Debug الشبكة محفوظ.
- التحكم بالجدار على الهاتف بالضغط المطول ثم التحريك والإفلات محفوظ.

## تشغيل محلي
```bat
npm install
npm test
npm run dev
```
ثم افتح:
`http://localhost:8787`

## نشر Cloudflare
```bat
npm install
npm run deploy
```
ثم استخدم رابط workers.dev نفسه.

## ملاحظة AI
Beginner عشوائي إلى حد كبير، Skilled يقيّم أقصر المسارات، Veteran يستخدم بحث Alpha-Beta بعمق 2، Expert بعمق 3 مع مرشحات جدران قريبة لتقليل عدد الفروع.


## تحسينات AI في v0.10
- اختيار الجدران أصبح مبنيًا على أقصر مسار فعلي للخصم.
- تقييم الجدار يحسب مقدار إطالة طريق الخصم مقابل الضرر على طريق الـAI.
- دفاع طارئ إذا كان الخصم على بعد حركة أو حركتين من الفوز.
- Veteran وExpert يستخدمان Alpha-Beta مرتبًا مع Iterative Deepening وTransposition Table.
- Expert محدود بميزانية بحث حتى يبقى خفيفًا على المتصفح.
- توجد عقوبة واضحة للتراجع غير المفيد.
- عندما يكون الـAI متقدمًا بوضوح، يوفر الجدران ويتجه للفوز بدل إهدارها.

## v0.10.0
- تدوير منظور الرقعة محليًا بحيث يرى اللاعب نفسه دائمًا من الأسفل وهدفه أمامه، بدون تغيير إحداثيات اللعبة الداخلية.
- دعم الدوران 90° للاعبين P3/P4 مع إبقاء Horizontal/Vertical بصريًا صحيحًا.
- أصوات خفيفة للحركة ووضع الجدار.
- تنبيه صوتي خفيف في الدور Online عند بقاء أقل من 8 ثوانٍ للاعب المحلي.
- رفع معاينة الجدار على الهاتف فوق الإصبع بنحو 44px حتى لا يحجبها الإصبع.
- Mixed AI: في 3 لاعبين يمكن اختيار مقعد AI واحد، وفي 4 لاعبين يمكن اختيار حتى مقعدين AI، مع اختيار المقاعد نفسها.
- أداة Render GUI موجودة داخل tools/RenderUpdater.


## جديد في v0.10 — AI داخل الغرف Online
- خيار **AI Players** موجود تحت Mode عند اختيار 3 أو 4 لاعبين.
- القيمة الافتراضية: `0`.
- 2 لاعبين: لا يمكن إضافة AI.
- 3 لاعبين: `0` أو `1` AI.
- 4 لاعبين: `0` أو `1` أو `2` AI.
- كل AI مضاف داخل الغرفة يستخدم مستوى **Veteran**.
- الغرفة تنتظر فقط عدد اللاعبين البشر المطلوب، والـAI يتحرك من السيرفر نفسه على Cloudflare وRender.
- مثال: 3 Players + 1 AI = لاعبان بشريان Online + Veteran AI.
